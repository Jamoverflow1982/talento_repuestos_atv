# ATV Repuestos

---

## ⚙️ Descripción del Proyecto

¡Bienvenido a **ATV Repuestos**! Somos tu solución integral para encontrar todos los repuestos y accesorios que tu auto necesita. Ofrecemos una amplia gama de productos, tanto originales como alternativos, para diversas marcas líderes. Nuestro objetivo es brindarte calidad y una experiencia de compra sencilla para mantener tu vehículo en óptimas condiciones.

---

## ✨ Características Principales

* **Catálogo de Productos:** Explora repuestos organizados por marcas principales (Fiat, Peugeot, Renault, Volkswagen).
* **Sección de Accesorios:** Encuentra elementos de diseño y tecnología para personalizar tu auto.
* **Productos Destacados:** Visualiza los artículos más vendidos en la página de inicio.
* **Diseño Responsivo:** Adaptado para una visualización óptima en todos los dispositivos.
* **Navegación Intuitiva:** Acceso rápido a las secciones de Inicio, Productos, Accesorios, Contacto y Carrito.
* **Formulario de Contacto:** Envía consultas si no encuentras el repuesto que buscas.
* **Newsletter:** Suscríbete para recibir novedades y ofertas.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura y semántica.
* **CSS3:** Estilos personalizados (`estilos.css`).
* **JavaScript (Vanilla JS):** Interactividad.
* **Font Awesome:** Iconografía para el diseño.
